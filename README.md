# ANDERUS — STAR RAIL NEXUS

Protótipo mobile-first do hub independente de Honkai: Star Rail. **Versão v0.3** para validação visual e funcional; não é uma versão final.

## Abrir o site

O arquivo [`index.html`](./index.html) é autocontido (CSS, JavaScript e principais imagens incorporados); algumas imagens, fontes e dados adicionais dependem de serviços públicos externos.

## Recursos presentes

Arquivo de personagens, kits e Eidolons, leitura contextual da Nexia (baseada em regras, sem ChatGPT API), Theme Studio, Endgame e planejamento de recursos.

## Avisos

Este site não é oficial e não possui associação com a HoYoverse. Estimativas são experimentais; os dados da conta salvos no navegador não devem ser considerados sincronizados entre dispositivos. A conexão com API de IA, importação automática plena, atualizações recorrentes e simuladores validados ainda não estão habilitados.

## Publicação

Este repositório deve ser hospedado no GitHub Pages pelo workflow em `.github/workflows/pages.yml`. Caso Pages ainda esteja desabilitado, habilite nas configurações do repositório em **Settings → Pages → Build and deployment → Source: GitHub Actions**.
